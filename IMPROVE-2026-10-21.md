# Improvement Deep-Dive — SIP-Booster-Relay — 2026-10-21

Companion to AUDIT-2026-10-21.md. Fork of NostrDanish/nosflare-style relay; serverless Nostr/SIP-01 relay on Cloudflare Workers + D1 + Durable Objects.

## Top recommendations (ranked, with effort S/M/L)

1. **[S] Enforce `DEPLOY_BUNDLE_SHA256` in stock config.** `src/config.ts:212` ships `DEPLOY_BUNDLE_SHA256 = ""` and `src/service/deploy.ts:139-151` only verifies the hash `if (config.DEPLOY_BUNDLE_SHA256)` — i.e. the pinned-commit protection (audit P0-3) is silently OFF by default, and the "verified" detail in the deploy log (`:151`) never appears. Fix: (a) compute `sha256sum worker.js` of the CI-built bundle at `DEPLOY_BUNDLE_REF` (405dc08…) and commit the value; (b) better, have `.github/workflows/build-worker.yml` emit the hash and fail release when config doesn't match; (c) make an empty value a loud startup warning (`console.error` + NIP-11 `limitation` note) rather than silent skip.
2. **[S] Replace the author's `SERVICE_OWNER_PUBKEY` default.** `src/config.ts:174` hardcodes the upstream author's pubkey (`90afdf…7b14`) as service owner; `src/service/auth.ts:8` grants `/admin` to it; `src/runtime-config.ts:39` only overrides when the operator sets the env var. Stock forks silently hand admin to the original author. Fix: default `""` → admin API disabled until explicitly configured (fail-closed), and document `SERVICE_OWNER_PUBKEY` as required for `/admin`. Same for `relayInfo.pubkey`/`contact` (`src/config.ts:236-238`) which also ship the author's identity.
3. **[S] Fix fork config drift in `DEPLOY_BUNDLE_URL`.** `src/config.ts:214` builds the bundle URL from `raw.githubusercontent.com/NostrDanish/SIP-Booster-Relay/...` — this fork's deploy API would fetch the *upstream author's* bundle, not this repo's. Point at `SIP-01/SIP-Booster-Relay` (and confirm the pinned ref exists here).
4. **[S] Bump `wrangler` ≥ 4.59.1.** `package.json` pins `^4.0.0`; CVE-2026-0933 (command injection in `wrangler pages deploy --commit-hash`, GHSA-36p8-mvp6-cv38) affects `>=4.0.0 <4.59.1`. Also bump `esbuild ^0.19.12 → ^0.28.2` (Aug 2026; 0.19 is 9 minors behind) and `typescript ^5.5 → ^5.9`.
5. **[S] Add a test/typecheck gate to CI.** `.github/workflows/build-worker.yml` builds + commits artifacts; `e2e-smoke.yml` probes the live relay daily — but no workflow runs `npm run typecheck` or `node tests/run-tests.mjs` on push/PR. A type error or broken test reaches main unchecked.

## Missing gates (CI/tests/protection)

- PR gate running `typecheck` + `tests/run-tests.mjs` — **missing**.
- gitleaks/secret-scan job — missing (repo docs instruct operators to paste keys/tokens; a gitleaks gate would catch a committed token).
- Branch protection on `main` — currently unprotected; CI itself force-commits `worker.js` back to main, so protection must exempt that bot or move artifacts to a release branch.
- `npm install --legacy-peer-deps` in build workflow is unpinned; use `npm ci` with a committed lockfile (no `package-lock.json` is tracked — add one).
