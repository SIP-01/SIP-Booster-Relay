# Security Audit — SIP-Booster-Relay — 2026-10-20 (re-run 2026-10-21)

## Summary
Serverless Nostr/SIP-01 relay on Cloudflare Workers + D1 + Durable Objects, forked from Spl0itable/nosflare. The fork remains security-*ahead* of upstream (verified pay-to-relay via kind-9735 zap receipts, removed outbound-WS SSRF in NIP-05 validation, isolated hosted deploy service, token-bucket rate limits wired in `src/durable-object.ts`, parameterized SQL, NIP-98-signed /admin). **Delta vs `audit/2026-10`: (1) DEPLOY_BUNDLE_SHA256 verification code now EXISTS in `src/service/deploy.ts` (hash checked, deploy refused on mismatch) — but the shipped value in `src/config.ts` is still `""`, so stock deploys skip verification; partial remediation. (2) The author's `SERVICE_OWNER_PUBKEY` default is still hardcoded.** Findings: 0 CRITICAL / 0 HIGH / 2 MEDIUM / 2 LOW.
